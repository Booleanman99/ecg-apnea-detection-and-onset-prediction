## Round 1 — Task B "learnable" bar

**Stamped 11:46, before any Task B number existed.** *"I would call short-horizon prediction learnable here if the H = 1 onset model beat prevalence AUPRC by ≥ 2× with CIs clear of prevalence across seeds, and errors concentrated away from signal-quality failures."*

**Amendment 1 (11:48 mtime, after a review of the bar, before any Task B number).** The bar can be passed by patient severity alone, so it additionally requires (i) within-night AUROC > 0.5 with a record-bootstrap CI clear of 0.5, computed over a/b test+validation nights with ≥ 5 onsets (undefined for control nights); and (ii) "away from quality failures" made concrete: the true-positive rate in the worst signal-quality tercile is not lower than in the best tercile. Then state whether it was met.

**Amendment 2 (11:58 mtime, before any Task B number).** The quality axis for clause (ii) is the beat-template signal-quality index (per minute, median Pearson correlation of each beat, R ± 0.25 s, with that minute's median beat), split into terciles by value. Flat-line, clipping and implausible-beat-count are kept as separate binary flags with counts, never as tercile axes. HRV, RR irregularity and beat count are excluded as quality axes because apnea changes them. AUROC(SQI → label) on train is reported next to the comparison; if it is far from 0.5 the comparison is partly a label comparison and is said to be.

**Amendment 3 (12:08:00 mtime, before any test number; validation numbers for LR, window-XGBoost and CNN existed).** The bar is evaluated on the single Task B model selected on validation AUPRC (ties → the simpler model, order LR < XGB < XGB-relative < CNN) before the test set is scored; other models are reported but do not count toward the bar. The headline deep-vs-baseline comparison is CNN vs the window-only feature models; XGB with subject-relative features is a second baseline with night-so-far context the CNN does not get.

**Amendment 3a (12:12; test metrics for all models were first displayed at 12:08:46, so this entry post-dates them).** A tie is a mean validation AUPRC within 0.005; "the model" for a stochastic family is the single seed whose validation AUPRC is the median of the three. The median-seed rule was already in `src/s6_evaluate.py` at 12:08:00, before the first test metric. Provenance: the first versions of the training stages wrote test *predictions* to disk at 12:04–12:06 although no test metric was computed before 12:08:46; the code was changed so that only `s6_evaluate.py` scores test, the early files were quarantined, regenerated through s6 and found byte-identical.

**Selection rule for both tasks**: highest mean validation AUPRC per task; the seed with the median validation AUPRC is the reported model; threshold = maximum F1 on validation. Of these, the median-seed rule is verified to have been in `src/s6_evaluate.py` at 12:08:00 (mtime), before the first test metric; the tie threshold (0.005, simpler model wins) was written at 12:12, after it; the file has since changed, so the other clauses cannot be shown from file times to predate the test, only from the author's log.

## Round 2 — stamped 17:58 (plan mtime 17:57:21), amended 18:01 (mtime), before any round-2 cross-validation number existed

Requested after round 1 was complete and its test numbers known. Round 1 stays in the report as the pre-registered result. Round-2 artefacts that existed before the stamp: the 6-night validation grid (17:48); a validation-only CNN variant script with causal running standardisation and polarity flips (17:42; it never completed, and it falls under the polarity exclusion below); a validation-only architecture screen script (17:53; no output before the stamp). An earlier copy of the cross-validation harness was started at 17:59 and stopped at 18:03 while still building feature tables; it computed no fold metric (author's attestation; its log was overwritten).

1. Nothing in round 2 reads a test row until the single promotion scoring. Selection = 6-fold grouped cross-validation over the 22 train + validation nights (folds balanced by severity class), reporting pooled out-of-fold AUPRC and mean within-night AUROC (nights with ≥ 5 positives and ≥ 5 negatives; control nights are therefore excluded from within-night AUROC but included in pooled AUPRC). The only prior round-2 artefact is a 6-night validation hyper-parameter grid (17:48), which informs the two XGBoost settings tried.
2. Candidates come from train-side diagnostics or standard practice only: causal multi-minute context for detection, night-so-far median/IQR scaling, causal probability smoothing, the two XGBoost settings, out-of-fold detector-history stacking and a cross-validated history length for Task B, and a validation-only architecture screen for the deep model. Polarity-flip augmentation is excluded because the observation that motivated it came from a test night. Within-night AUROC as the criterion is motivated by the train-side single-feature finding reported before any test number (within-night 0.7–0.9 vs pooled 0.63) and by validation within-night AUROCs (CNN 0.579 vs XGBoost 0.755) that are computable from validation predictions written before any test number (12:06) but were first computed at 12:44, after it. Cap: ≤ 8 model configurations per task (feature set × XGBoost setting); the smoothing constant (4 values) is a post-processing choice reported for every model. The full CV table is reported.
3. Promotion rule, per task: the comparator is the best round-1 family under the same CV. A round-2 pipeline replaces the round-1 final only if the mean of the six per-fold paired differences in within-night AUROC (candidate − comparator, same folds) exceeds twice the standard error of those differences, AND its pooled OOF AUPRC is not lower. If CV ranks a round-1 family above the round-1 final, that alone counts as a promotion, disclosed, with a note where it coincides with the round-1 test winner.
4. If promoted: retrain on all 22 nights; threshold = maximum F1 on the pooled OOF predictions (applied to a model trained on 22 nights, which scores on a slightly different scale); seed = median of 3 by OOF AUPRC; then ONE test scoring, reported as round 2 beside round 1 with this section quoted and timestamps. The candidate confirms in writing before that scoring runs. If nothing is promoted, test is not touched again.
5. Everything causal for both tasks: context = past and current minute only for detection, history only for prediction; smoothing uses past outputs only; scaling uses the night so far. Task B detector-history stacking is nested: inside each outer fold the training nights' detector probabilities are inner out-of-fold values and the held-out fold's come from a detector trained on the training folds; for the final retrain, training features are 6-fold OOF and test features come from the detector trained on all 22 nights.
